## Main project — Clinical nutrition desktop app *(private, in development)*

A desktop application for clinical nutritionists: patient assessment, meal plans by diagnosis or hospital diet, enteral and parenteral nutrition support, and clinical PDF reports.

- **Stack:** React + TypeScript (Vite), Python (pywebview), SQLite
- **Clinical rules engine:** 27 hospital diets and 60+ condition profiles that filter 600 recipes by ingredient, texture and macronutrients
- **Local AI:** an Ollama-based assistant that uses tool calling to adjust meal plans — no data leaves the computer
- **Nutrition support:** administration-route suggestions, drip-rate calculator and pediatric formulas

The source code is private because this is a commercial product. A case study with screenshots is coming soon.
